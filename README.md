# 🐾 1С:Груминг-салон – полнофункциональная учётная система

**Учебный проект, выполненный в рамках курса 1С разработчик**  
Конфигурация автоматизирует все ключевые процессы салона по уходу за животными: от записи клиентов и оказания услуг до бухгалтерского учёта, расчёта зарплаты и аналитики для руководителя.

> ✅ Работоспособность кода подтверждена.  
> ✅ Соответствует техническому заданию (ТЗ объёмом более 100 страниц).  
> ✅ Внедрены механизмы **Библиотеки стандартных подсистем (БСП)**.

---

## 📌 Основные возможности

### 🧾 Управление торговлей и складом
- Справочники: Организации, Склады, Номенклатура (товары/услуги), Контрагенты, Договоры, Сотрудники.
- Документы: Поступление товаров, Реализация товаров и услуг, Поступление услуг.
- **Партионный учёт** по срокам годности.
- **Метод списания FEFO** (First Expire First Out) – автоматический выбор партии с наименьшим сроком годности.
- Контроль остатков при списании с настраиваемым запретом отрицательных остатков.
- Расчёт себестоимости товаров (регистр «Учёт затрат»).

### 💰 Касса, банк и денежные средства
- Кассовые документы (Поступление/Расход денежных средств) с поддержкой наличных и безналичных (эквайринг).
- Банковские документы (Поступление/Списание с расчётного счёта).
- Учёт в разрезе касс, банковских счетов и эквайринговых терминалов.
- Отчёты: «Движение наличных денег», «Безналичная оплата», «Контроль остатков денежной массы».

### 📅 Запись клиентов и планировщик
- Документ «Запись клиента» с автоматическим расчётом длительности услуги.
- **Обработка-планировщик** с отображением занятости мастеров (день/неделя/месяц).
- Цветовая индикация: запись выполнена / не выполнена.
- Контроль повторной реализации – запрет дублей.

### 📊 Дашборд руководителя
- Выручка, средний чек, количество записей, процент завершённых заказов.
- Гистограмма выручки по дням месяца.
- Круговые диаграммы:
  - Структура визитов по рекламным источникам.
  - Выручка по сотрудникам.
  - Выручка по услугам (доля >10%).
- Загрузка курсов валют (доллар, евро, тенге) и новостей (с настройкой темы).

### 💼 Бухгалтерский учёт (План счетов, проводки)
- План счетов «Хозрасчётный», регистр бухгалтерии.
- Автоматическое формирование проводок по всем хозяйственным операциям.
- Отчёты: «Оборотно-сальдовая ведомость», «Оборотно-сальдовая ведомость по счёту».
- Журналы: «Журнал проводок», «Журнал хозяйственных операций».

### 🧑‍💼 Расчёт заработной платы
- План видов расчёта «Начисления» (оклад, больничный, премия).
- Регистры: «Кадровая история сотрудников», «Графики работы», регистр расчёта.
- Документы: Начисление зарплаты (с автозаполнением по окладам), Больничный лист, Премия.
- Отчёт по начислениям (сотрудники → виды расчёта → периоды).

### 🔌 Интеграции и импорт
- **Загрузка прайс-листов поставщиков из Excel** (xlsx) с созданием документа «Установка цен поставщика».
- Автоматическая подстановка цен в документы поступления.
- Регистр сведений «Цены номенклатуры поставщиков» (срез последних).

### ⚙️ Библиотека стандартных подсистем (БСП)
Внедрены и адаптированы подсистемы:
- **Базовая функциональность** (общие процедуры, роли).
- **Обновление версий ИБ** (обработчики обновления).
- **Пользователи** (управление доступом).
- **Организации** (единый интерфейс).
- **Префиксация объектов** (автонумерация с префиксами организаций).
- **Валюты** (загрузка курсов с сайта 1С).
- **Дополнительные отчёты и обработки** (внешний отчёт «Исполнение заказов клиентов»).

## 🚀 Установка и запуск

### Требования
- Платформа 1С:Предприятие 8.3 (не ниже версии 8.3.20).
- Режим совместимости – «Управляемые формы».

### Инструкция
1. Скачайте файл выгрузки конфигурации `.cf` (или `.dt`) из папки `/Build`.
2. Создайте новую информационную базу.
3. Загрузите конфигурацию через «Конфигуратор» → «Конфигурация» → «Загрузить конфигурацию из файла».
4. Запустите базу в режиме «1С:Предприятие».
5. При необходимости выполните первоначальное заполнение справочников (организации, склады, статьи затрат).
